# 🚀 十倍股星辰大海白名单 (Hyper-Growth Concepts Framework)

本框架定义了针对能支撑“5年10倍营收与利润”增长的超级赛道进行定点监控的逻辑。

## 一、 触发条件 (Router Trigger)
当用户指令中包含“星辰大海”、“十倍股”、“扫一下白名单”、“黄金坑”等意图时，跳过个股分析和全市场扫描，**强制执行本框架**。

## 二、 执行流水线

### Step 1. 读取超级白名单
智能体必须从 `config/hyper_growth_concepts.json` 中读取用户定义的十倍股赛道名称。

### Step 2. 启动定点爆破扫描
调用内置的轻量级扫描脚本，该脚本只对白名单中的概念拉取近期 K 线，计算缩量与均线支撑：
```bash
python scripts/scan_hyper_growth.py --support_ma 20 <输出目录路径>
```
> `--support_ma` 默认为 20（20日线支撑）。智能体可根据市场强弱动态传入 10 或 60。

### Step 3. 黄金坑雷达渲染
脚本执行后，智能体提取数据并强制按照以下 Markdown 格式输出预警报告。

## 三、 研报渲染规范 (Markdown Demo)

```markdown
# 🚀 星辰大海：十倍股黄金坑雷达 (Hyper-Growth Radar)
*扫描赛道：人形机器人, 固态电池, 脑机接口等 [X] 个白名单概念*

> **🎯 策略定义**：仅监控未来5年具备10倍业绩爆发潜力的硬核赛道。寻找“曾经爆火 + 近期极度缩量回调 + 精准回踩生命线”的绝佳左侧上车点。

## 🟢 黄金坑触发区 (缩量回踩，绝佳买点)
> 判定标准：当前处于回调趋势，但单日成交额相比高点已大幅萎缩（洗盘），且指数精确触达设定的支撑均线。
1. **[概念名称]**：完美触发！
   * **技术面特征**：已回踩 [20] 日线 | 较前高缩量达 [X]%
   * **量化点评**：主力洗盘迹象明显，散户筹码断层。此时博弈反弹赔率极高。
2. **[概念名称]**：...

## 🟡 趋势震荡区 (可逢低定投)
1. **[概念名称]**：未触及支撑位，但整体趋势向上。
2. **[概念名称]**：...

## 🔴 破位危险区 (基本面/情绪面双杀，暂时规避)
> 判定标准：有效跌破 60 日牛熊分界线，且呈现放量下跌趋势（主力出逃）。
1. **[概念名称]**：放量跌破支撑线，短期情绪崩塌，等待右侧企稳。
```

## 四、 物理归档与台账记录 (Archiving & Ledger)
报告生成后，智能体必须强制执行以下两次归档动作，以支持未来的量化回测：

1. **研报物理归档**：
   * 将 Markdown 报告保存至：`Company_Research_Reports/00_Market_Radars/Hyper_Growth/YYYYMMDD_宏观天气_十倍股雷达.md`
2. **回测台账写入**：
   * 将核心结果追加写入当前工作区下的 `tracking/radar_ledger.csv` 文件中，字段按顺序包括：
     * `Date`: 当前日期 (如 2026-07-06)
     * `Radar_Type`: `Hyper_Growth`
     * `Macro_Weather`: 当前宏观天气（如果未调用天气则填 `未知`）
     * `Top_Long_Sectors`: 用 `|` 分隔的 2-3 个已跌入黄金坑的白名单概念
     * `Top_Short_Sectors`: 用 `|` 分隔的已破位危险白名单概念
     * `Report_Path`: 相对文件路径 (如 `00_Market_Radars/Hyper_Growth/...`)

# 🚁 A股板块轮动与防高潮雷达 (Sector Radar Framework)

本框架定义了当用户下达“扫描全市场/板块轮动/看大盘”等宏观指令时，智能体必须执行的专属工作流，以寻找最佳上车板块并规避高潮踩踏风险。

## 一、 触发条件 (Router Trigger)
当接收到涉及全市场扫描的指令时，智能体**必须跳过所有个股分析 SOP**，直接进入本框架。

## 二、 执行流水线 (Sector SOP)

### Step 1. 启动量化扫描探针
在终端执行内置的板块扫描脚本。该脚本会自动遍历东方财富全市场 86 个细分行业板块，进行量价动能与拥挤度的计算：
```bash
python scripts/scan_sector_rotation.py <输出目录路径>
```
> 若无指定目录，可默认输出至当前工作区下的 `Market_Radars/` 文件夹。

### Step 2. 读取扫描报告
脚本执行完毕后，会生成 JSON 数据文件及初步排名的 Markdown 文件。智能体必须使用 `view_file` 工具读取生成的分析数据。

### Step 3. 终极雷达研报生成
结合扫描出的硬数据，结合当前的宏观天气（如果有），生成并向用户输出最终的《A股板块动能与拥挤度雷达》Markdown 报告。

## 三、 研报核心维度与渲染规范 (Markdown Demo)

必须严格按照以下维度和格式输出最终的板块雷达报告：

```markdown
# 🚁 极客轮动雷达 (A-Share Sector Rotation Radar)
*生成时间：[当前日期]*

## 🟢 左侧启动区 (适合底仓潜伏)
> 判定标准：均线刚发生多头排列或 MACD 金叉，且换手率与成交额占比健康（不拥挤）。
1. **[板块名称]**：动能刚启动 | 估值分位 [X]% | 当前拥挤度 [X]%
2. **[板块名称]**：...

## 🟡 稳健右侧区 (顺势而为，适合主升浪)
> 判定标准：资金连续流入，成交额温和放大（较20日均量放大30%-50%），尚未触及拥挤红线。
1. **[板块名称]**：量价齐升 | 资金连续流入 | 核心龙头标的：[举例]
2. **[板块名称]**：...

## 🔴 高潮预警区 (拥挤度极度恶化，严禁追高)
> 判定标准：板块单日成交额占全市场总成交额发生畸变（如飙升至 8% 以上），高位爆量换手。
1. **[板块名称]**：⚠️ 严重拥挤！成交额占比飙升至 [X]% | 估值分位 [X]% | 建议：逢高兑现，切勿接盘！
2. **[板块名称]**：...
```

## 四、 后续联动 (Auto-Linking)
在输出完雷达报告后，智能体应主动询问用户：“**是否需要我为您针对上述某个优质板块中的龙头股，切换至【个股深度调研模式】？**”

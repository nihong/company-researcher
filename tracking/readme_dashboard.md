# 全局导航页 (README.md) 极客数据看板规范

为了追求最高效的买方决策体验，工作区根目录的 `README.md` 被定义为**极客数据看板**。该文件禁止人工或 AI 拼凑排版，必须由底层数据表 `ledger.csv` 经脚本全自动渲染生成。

## 渲染核心约束

1. **容量限制 (Top 20 原则)**
   - 坚决杜绝无限拉长的流水账。看板**只显示最近 20 份**最新生成的研报记录（基于 `调研日期` 倒序截取）。

2. **噪音过滤与字段提纯 (极简决策原则)**
   - 不展示诸如市盈率 (PE)、换手率、长篇复盘备注等冗余数据。
   - **仅保留交易核心的 6 个维度**：
     1. 🗓 **调研日期**
     2. 🎯 **标的**：必须合并展示股票名称、带后缀的代码以及申万精细化行业。
     3. 💡 **评级 (得分)**：S/A/B/C/D 分档，必须附加 Markdown 强调格式（如 S 级满仓强推，D 级带删除线或 ❌ 警示）。
     4. 🚦 **资金状态**：必须保留 `🟢/🟡/🔴` 全彩 Emoji 图标。
     5. ⚡️ **买方核心决策**：提纯为极简的强执行指令（如“右侧建仓”、“坚决规避”），并对核心动作加粗。
     6. 🔗 **研报归档**：必须提供 Markdown 可直接点击的相对路径链接。

3. **美学与视觉规范**
   - 顶部需附带盾牌徽章（Shields.io），彰显系统的工业级品质（Agent名称、在线状态等）。
   - 采用对齐标准的 Markdown 表格。
   - 底部附带自动生成的系统水印（如 `Powered by company-researcher`）。

## 执行途径

在技能库的流水线第 16 步，完成 `ledger.csv` 台账的写操作后，无需再手动更新 README。而是统一调度专用脚本一键全量渲染：
```bash
python scripts/render_dashboard.py <当前工作区路径>
```
